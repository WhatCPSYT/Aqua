Basic Setup Guide

1. Inviting the Bot

Click the invite link on the main page. Ensure you grant the bot the recommended administrative permissions so all custom modules (like AutoMod and moderation actions) work without conflicts.

2. Checking Prefix / Slash Commands

Aqua operates fully on Discord's modern Slash Command architecture. Simply type the following in any text channel to browse available menus:


/help

Ticket System Setup

Important: Bot Permissions & Role Hierarchy!
1. Make sure Aqua has been granted both Manage Roles and Manage Server permissions in your server settings.
2. Crucial Step: Go to Server Settings -> Roles, and drag the Aqua Bot role so that it is positioned HIGHER than your standard user roles and Support roles.

1. Configure Ticket Options

Run the configuration command to set up panel texts, log channels, voice channel creation, and support roles:


/ticket-config

Available parameters:

  • title: Embed title for the ticket panel.
  • description: Embed description (supports Discord Markdown, quotes, headings, and \n for line breaks).
  • button: Custom text displayed on the open ticket button.
  • logs: Channel where ticket transcripts and close logs will be sent.
  • voice: Set to true or false (automatically creates a dedicated Voice Channel for each opened ticket).
  • role: Select the Ticket Support Role (members with this role get access to newly opened tickets).
Discord Text Formatting Reference:
You can style your description text with full Discord formatting syntax:
\n — New line / Line break
**text** — Bold text
*text* — Italic text
# Title — Header 1 (Big Text)
## Title — Header 2 (Medium Text)
### Title — Header 3 (Small Header)
> text — Quote Block
>>> text — Multi-line Quote Block
`text` — Inline Code
~~text~~ — Strikethrough

Full Command Example:
/ticket-config title: 🎫 Support Hub description: # Need Assistance?\n> Click below to open a private ticket.\n\n### Rules:\n* Be polite\n* Describe your issue button: Create Ticket logs: #ticket-logs voice: true role: @Support Team

2. Send the Ticket Panel

Once configuration is saved, publish the panel to your support channel:


/ticket-setup
Never delete ticket channels manually!
Always close tickets exclusively by clicking the built-in 🔒 Close Ticket or 📝 Close with Reason buttons inside the support channel. This allows Aqua to compile chat transcripts and log them properly.

Verification Gate

Important: Verification Requirements!
1. The bot must have the Manage Roles permission enabled.
2. Role Hierarchy Rule: In your Discord Server Settings, the Aqua integration role MUST be dragged and placed ABOVE the Member / Verified role that you want it to assign.

1. Configure Verification System

Set up your custom welcome message, title, button text, and verified role before generating the panel:


/verification-config

Available parameters:

  • title: Embed title for the verification panel.
  • description: Main panel description (supports Discord Markdown, quotes, headings, and \n for line breaks).
  • button: Text shown on the verification trigger button.
  • role: Role assigned automatically to users after solving the verification captcha.
Discord Text Formatting Reference:
You can style your description text with full Discord formatting syntax:
\n — New line / Line break
**text** — Bold text
*text* — Italic text
# Title — Header 1 (Big Text)
## Title — Header 2 (Medium Text)
### Title — Header 3 (Small Header)
> text — Quote Block
>>> text — Multi-line Quote Block
`text` — Inline Code
~~text~~ — Strikethrough

Full Command Example:
/verification-config title: 🌸 Aqua Verification description: # Welcome to **Aqua Community**! 🌊\n\n> To gain full access to all channels, please verify yourself.\n\n### Instructions:\nClick the button below and solve a quick math problem. button: Start Verification role: @Member

2. Send Verification Panel

Once configuration is saved, send the interactive verification embed into your current channel:


/verification-setup
